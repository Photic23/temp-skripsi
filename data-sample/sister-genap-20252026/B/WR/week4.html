Selamat siang, Pak Harry, tim Asdos, dan teman-teman.

Saya izin membagikan refleksi saya mengenai materi antarmuka.

Selama perkuliahan minggu ini, saya mempelajari bahwa antarmuka bukan sekadar elemen visual, melainkan jembatan antara manusia dan teknologi yang harus dirancang dengan mempertimbangkan usability dan user experience. Konsep ini diperkuat oleh Shneiderman’s Eight Golden Rules, yang menjadi acuan dalam mengevaluasi kualitas desain antarmuka. Salah satu prinsip yang paling menarik bagi saya adalah "Reduce short-term memory load", karena sering kali saya merasa kesulitan menggunakan aplikasi yang mengharuskan pengguna mengingat terlalu banyak informasi dalam satu waktu. Hal ini mengingatkan saya bahwa antarmuka yang baik harus mempermudah interaksi, bukan malah membebani pengguna.

Selain itu, diskusi mengenai berbagai bentuk user interface (UI), seperti Graphical User Interface (GUI), Voice User Interface (VUI), dan Augmented Reality/Virtual Reality (AR/VR), memberikan wawasan baru tentang bagaimana teknologi terus berkembang agar interaksi semakin natural dan intuitif. Saya menyadari bahwa setiap jenis antarmuka memiliki tantangan tersendiri, misalnya VUI harus mempertimbangkan aksen pengguna, sementara UI untuk wearables harus lebih ringkas dan efisien karena keterbatasan layar.

Sekian,
